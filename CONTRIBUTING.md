# Contributing to SystemUnite4

Thank you for your interest in contributing to the **SystemUnite4** project!

## How to Contribute
1. **Report Bugs:** Open an issue describing the bug, hardware setup, and steps to reproduce.
2. **Suggest Features:** Open an issue proposing new modules (e.g., adding pH or DO sensors).
3. **Pull Requests:**
   * Fork the repository.
   * Create a feature branch (`git checkout -b feature/NewSensor`).
   * Commit your changes with clear messages.
   * Push to the branch and open a Pull Request.

## Code Guidelines
* Follow non-blocking programming structures (`millis()` over `delay()` where applicable).
* Keep pin definitions modular and documented.
